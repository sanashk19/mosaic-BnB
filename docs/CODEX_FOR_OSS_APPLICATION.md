## Short Description

UQUVLI is an open-source accessible digital life-skills learning platform for children with special educational needs and intellectual disabilities. It provides adapted lessons, interactive trainers, role-based dashboards for students, parents, teachers and researchers, downloadable DOCX lesson materials, progress tracking and research export tools.

## Why This Project Matters

UQUVLI supports inclusive education by helping children practice real digital situations in a calm, structured interface: messaging, email, public services, transport, health, hygiene, household finance and safety. The project is important because many existing education platforms are not designed around one-step screens, large controls, simple language, teacher-led pacing and research-friendly observation.

The platform is already live at https://uquvli.uz and is intended for continued development with schools, families, teachers and researchers. Even if the open-source repository is young, the project plays an important role by turning inclusive digital literacy methods into reusable software that other teams can inspect, adapt and improve.

## Maintainer Role

I am the primary maintainer and builder of the platform. I use OpenAI Codex heavily to develop the project, fix bugs, implement frontend flows, improve accessibility, maintain documentation, refactor code and plan further work. I intend to keep developing UQUVLI as an open-source project.

## Current Project Scope

- 30 adapted lessons across 7 modules.
- 39 interactive trainers for practical digital skills.
- Student, parent, teacher and researcher dashboards.
- Teacher tools for class lesson control and DOCX lesson downloads.
- Researcher tools for participant overview, questionnaires, event logs and XLSX export.
- Russian and Uzbek localization support.
- Privacy-first OSS repository without production secrets or real participant data.
