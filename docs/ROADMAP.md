# Roadmap

This roadmap is intentionally focused on work that improves the open-source value of UQUVLI.

## Near Term

- Add automated tests for login, lesson completion and researcher export.
- Add accessibility checks for keyboard navigation, focus order and color contrast.
- Document how schools can run a private pilot without sending learner data to third parties.
- Add screenshots and short videos for the main role flows.
- Add a lesson authoring guide for teachers and researchers.

## Platform

- Extract trainer patterns into reusable components.
- Add a safer storage adapter boundary for SQLite/Postgres deployments.
- Add import/export tools for lesson packs.
- Add role-specific onboarding for local pilots.
- Improve Uzbek localization coverage and review.

## Education And Research

- Publish an anonymized sample dataset for analytics demos.
- Add more adaptive lesson templates for everyday digital services.
- Improve before/after questionnaire reporting.
- Add accessibility review notes for each trainer.

## Community

- Label beginner-friendly issues.
- Publish contribution examples for teachers, translators and developers.
- Add public discussion templates for lesson ideas and accessibility feedback.
